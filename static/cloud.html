What is enforced by the database?

  • Customers can read their own orders; staff and analysts can read the permitted order rows.
  • Checkout runs through the place_order database function.
  • Stock changes run through update_stock; catalogue additions run through admin_add_product.
  • Changing or hiding a button in this page does not grant database access. PostgreSQL still checks the signed-in user's role.
